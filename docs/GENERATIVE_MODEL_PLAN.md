# 🧠 نقشه راه مدل یادگیرنده (Generative) — جایگزین warp دستی

## وضعیت فعلی و چرا کافی نیست

موتور فعلی = **هندسی/قاعده‌محور** (warp + سایه). سقفش همین است:
- تغییرات ملایم را خوب انجام میدهد
- اما «نوک بالا در نیم‌رخ» یا تغییرات بزرگ → مصنوعی دیده میشود
- MediaPipe هم بعد از warp شدید لندمارک‌ها را گم میکند

**راه حل نهایی صنعت: مدل مولد آموزش‌دیده (Diffusion)** — مثل Gemini/Flux که عکس واقعی تولید میکند.

## 📦 دارایی‌های آماده ما (امروز)

| دارایی | تعداد | کاربرد |
|--------|-------|--------|
| جفت قبل/بعد لیبل‌دار | ۵۹۲+ | آموزش supervised |
| لندمارک ۴۷۸ نقطه‌ای CelebA | ۲۰۲,۵۹۹ | کنترل هندسه |
| امتیاز زیبایی SCUT | ۵,۵۰۰ | انتخاب بهترین خروجی |
| موتور آناتومیک فعلی | ۱۷ استایل | **دیتاست ساز** |

## 🗓 برنامه سه‌فازی

### فاز ۱ — فردا: تولید ۲۰k دیتاست سینتتیک
```bash
./venv/bin/python3.11 datasets/generate_pairs.py --count 20000
# ~12 دقیقه روی همین سیستم! (27 جفت/ثانیه)
```

### فاز ۲ — این هفته: LoRA روی Stable Diffusion
- ابزار: `diffusers` + `controlnet-aux` (رایگان، open-source)
- GPU: Colab Pro (~۱۰$) یا Kaggle (۳۰ ساعت رایگان/هفته)
- ورودی: عکس + لندمارک + متن فارسی → خروجی: عکس ادیت‌شده واقعی
- زمان آموزش: ~۴-۶ ساعت برای نسخه اولیه

### فاز ۳ — تست A/B با کاربران واقعی
- خروجی موتور فعلی vs مدل جدید → کدام طبیعی‌تر؟
- معیار: کاربر نباید بفهمد ادیت شده (هدف تو)

## 🎯 معماری پیشنهادی نهایی اپ

```
کاربر متن میفرستد
   ↓
NLU (فعلی) → area/action/intensity
   ↓
اگر تغییر ملایم → موتور فعلی (سریع، ۶ ثانیه)
اگر تغییر بزرگ/نیم‌رخ → مدل Diffusion (۱۵ ثانیه، کیفیت فوق‌واقعی)
   ↓
ترکیب: موتور فعلی پایه + Diffusion refinement
```

## ⚙️ قدم فردا صبح (به ترتیب)

1. تولید 20k دیتاست (۱۲ دقیقه)
2. آپلود به Kaggle Dataset (رایگان)
3. نوت‌بوک آموزش LoRA آماده میکنم — فقط run بزنی
4. تا عصر: اولین مدل مولد خودت!
